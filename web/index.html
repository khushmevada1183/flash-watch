⚠️ Why "Web Bluetooth API globally disabled" happens in Brave:

Brave blocks all Web Bluetooth requests by default for fingerprint protection. You can enable it in 15 seconds:

1
Copy the flag link:
2
Paste into address bar and press Enter: brave://flags/#brave-web-bluetooth-api
3
Set Web Bluetooth API from Default (Disabled) to Enabled, then tap Relaunch.
💡 Alternative: Open this link in Google Chrome or Microsoft Edge where it works immediately.
🍏 Running on iPhone / iPad:

Apple WebKit blocks Web Bluetooth in Safari, Chrome, and Firefox on iOS. To connect directly from an iPhone, use Bluefy (a free iOS browser that injects standard Web Bluetooth support):

🚀 Open in Bluefy App 📲 Get Bluefy (App Store)
Once opened in Bluefy, tap Connect Watch and select your FLASH smartwatch!
🤖 Running on Android Phone / Tablet:
1
Use Google Chrome, Samsung Internet, or Microsoft Edge (all support Web Bluetooth on HTTPS).
2
Turn Bluetooth and Location ON in your phone's quick settings (Android requires location permission for BLE scanning).
3
Important: Ensure the official boAt Wearables app is closed or uninstalled, and unpair the watch in phone Bluetooth settings. The watch only accepts 1 connection!
💻 Desktop & Laptop Instructions:

Supported out of the box in Google Chrome, Microsoft Edge, and Opera. If using Firefox or Safari on macOS, run the local PC bridge:

python3 server.py --lan
